DATE: 2026
VERSION: 2.0.1

================================================================================
 OVERVIEW
================================================================================

Added a collapsible sidebar identical in behaviour to Kaggle's sidebar:
  • A toggle button collapses the sidebar to a narrow icon-only rail (56px)
  • Expanding restores it to the full width (224px)
  • Smooth CSS transition (300ms ease-in-out)
  • When collapsed: nav labels hidden, icons remain clickable with tooltips
  • When collapsed: a re-open button appears in the TopBar left side
  • State is held in Layout.tsx and passed down as props

Only 3 files were modified. All other files are unchanged.

================================================================================
 TRANSITION ANIMATION
================================================================================

CSS:  transition-all duration-300 ease-in-out
      (on the <aside> element)

This smoothly animates:
  - width:   224px ↔ 56px
  - Content fades out as width narrows (via overflow-hidden)

The main content area also has:
  transition-all duration-300
  (on the flex-1 content wrapper in Layout.tsx)

This makes the content expand/contract smoothly as the sidebar opens/closes.
