1.  INTRODUCTION
────────────────────────────────────────────────────────────────────────────────

This tutorial course teaches you to build a production-grade Computational Fluid
Dynamics (CFD) web application for piping networks, similar in capability to
commercial packages such as PipeFlow Expert, EPANET, or AFT Fathom — but
entirely open-source and running in any web browser.

The application you will build:
  • Accepts arbitrary pipe-network topologies drawn interactively on a canvas.
  • Solves steady-state flow using Hardy-Cross or Newton-Raphson (Todini-Pilati).
  • Colour-maps each pipe by velocity, pressure drop, temperature, or Reynolds
    number in real time after convergence.
  • Provides an interactive Moody Chart with hover, zoom/pan, and user points.
  • Offers ten engineering calculators: Darcy-Weisbach, Reynolds, water hammer,
    heat transfer, minor losses, pump power, pipe sizing, compressible flow,
    two-phase flow, and dimensionless numbers.
  • Persists networks in SQLite (dev) or PostgreSQL (prod) via async SQLAlchemy.
  • Exposes a fully-documented RESTful API with 30+ endpoints.
  • Optionally accelerates friction-factor loops via a C++ pybind11 extension.

────────────────────────────────────────────────────────────────────────────────
5.  GOVERNING EQUATIONS OF PIPE FLOW
────────────────────────────────────────────────────────────────────────────────

All fluid flow is governed by the Navier-Stokes (NS) equations, which express
conservation of mass, momentum, and energy for a Newtonian fluid.

CONSERVATION OF MASS (Continuity):
  ∂ρ/∂t + ∇·(ρu) = 0

For incompressible flow (ρ = constant):
  ∇·u = 0      ← divergence-free velocity field

CONSERVATION OF MOMENTUM:
  ρ(∂u/∂t + u·∇u) = −∇p + μ∇²u + ρg

  where:
    u   = velocity vector [m/s]
    p   = pressure [Pa]
    μ   = dynamic viscosity [Pa·s]
    ρ   = density [kg/m³]
    g   = gravitational body force [m/s²]

CONSERVATION OF ENERGY:
  ρcₚ(∂T/∂t + u·∇T) = k∇²T + Φ

  where:
    T   = temperature [K or °C]
    cₚ  = specific heat capacity [J/(kg·K)]
    k   = thermal conductivity [W/(m·K)]
    Φ   = viscous dissipation [W/m³] (small for most liquids)

PIPE-FLOW SIMPLIFICATION (steady, fully-developed, axisymmetric):
  The axial momentum equation becomes an ODE in r:
    (1/r) d/dr (r du/dr) = (1/μ) dp/dx

  Integrating twice with no-slip (u=0 at r=R):
    u(r) = −(1/4μ)(dp/dx)(R² − r²)    [Hagen-Poiseuille profile]

  Mean velocity:
    V = Q/A = −(R²/8μ)(dp/dx)

  Rearranging for pressure gradient:
    Δp = 128μLQ / (πD⁴)    [laminar only]

  The general Darcy-Weisbach relation (valid all Re):
    Δp = f · (L/D) · (ρV²/2)
    hL = f · (L/D) · V²/(2g)    [head loss in metres]

────────────────────────────────────────────────────────────────────────────────
6.  REYNOLDS NUMBER AND FLOW REGIMES
────────────────────────────────────────────────────────────────────────────────

  Re = ρVD/μ = VD/ν

  Physical interpretation: Re is the ratio of inertial to viscous forces.

  FLOW REGIMES:
  ┌─────────────────┬────────────────────────────────────────────────────┐
  │ Re Range        │ Regime                                             │
  ├─────────────────┼────────────────────────────────────────────────────┤
  │ Re < 2 300      │ Laminar — ordered, parabolic profile, f=64/Re      │
  │ 2300 ≤ Re < 4000│ Transitional — intermittent turbulence, avoid      │
  │ Re ≥ 4 000      │ Turbulent — chaotic 3D fluctuations, log profile   │
  └─────────────────┴────────────────────────────────────────────────────┘

  WORKED EXAMPLE:
    Water at 20 °C: ρ=998 kg/m³, μ=1.002×10⁻³ Pa·s, ν=1.004×10⁻⁶ m²/s
    Pipe D=50 mm, V=1.5 m/s
    Re = 1.5 × 0.05 / 1.004×10⁻⁶ = 74 701 → Fully turbulent

  TRANSITION NOTE:
    In practice, well-designed lab systems can maintain laminar flow to Re≈20000
    with extreme care. For engineering design, always assume turbulent for Re>4000.

────────────────────────────────────────────────────────────────────────────────
7.  FRICTION FACTORS — LAMINAR TO TURBULENT
────────────────────────────────────────────────────────────────────────────────

LAMINAR (Re < 2300):
  f = 64/Re    (exact, derived from Hagen-Poiseuille)

TURBULENT — SMOOTH PIPE (Prandtl 1935):
  1/√f = 2.0 log₁₀(Re√f) − 0.8    (implicit; iterate)

TURBULENT — ROUGH PIPE: COLEBROOK-WHITE (1939):
  1/√f = −2 log₁₀( ε/(3.7D) + 2.51/(Re√f) )

  Accuracy: ±1% for 4000 < Re < 10⁸, 0 ≤ ε/D ≤ 0.05
  Method: Picard iteration (10–20 steps, converges to 12 significant figures)

SWAMEE-JAIN (1976) — EXPLICIT APPROXIMATION:
  f = 0.25 / [log₁₀(ε/(3.7D) + 5.74/Re⁰·⁹)]²
  Error: ±3% vs Colebrook-White. Used as initial guess in our solver.

CHURCHILL (1977) — UNIFIED FORMULA (all Re, smooth+rough):
  f = 8 [(8/Re)¹² + 1/(A+B)^(3/2)]^(1/12)
  A = [−2.457 ln((7/Re)⁰·⁹ + 0.27 ε/D)]¹⁶
  B = (37530/Re)¹⁶

  Advantage: Differentiable everywhere → used when Newton-Raphson Jacobian needs ∂f/∂Q.

VON KÁRMÁN FULLY-TURBULENT ASYMPTOTE (Re → ∞):
  1/√f = −2 log₁₀(ε/3.7D)

  This gives the horizontal asymptote on the Moody chart.
  Pipes with ε/D > 0 always approach this limit at high Re.

────────────────────────────────────────────────────────────────────────────────
8.  DARCY-WEISBACH HEAD-LOSS MODEL
────────────────────────────────────────────────────────────────────────────────

FUNDAMENTAL RELATIONS:
  hL = f · (L/D) · V²/(2g)     [m — head loss]
  ΔP = f · (L/D) · ρV²/2      [Pa — pressure drop]
  Q  = V · πD²/4               [m³/s — volumetric flow rate]

RESISTANCE COEFFICIENT:
  Define r = f·L/(2g·A²·D) so that:
    hL = r·Q|Q|    (sign convention: positive in flow direction)
    ΔP = ρg·hL

  The Newton-Raphson solver uses r and its derivative ∂(r·Q|Q|)/∂Q = 2r|Q|.

WALL SHEAR STRESS:
  τw = ρ·f·V²/8 = f·(D/4)·(−dP/dx)/2

SHEAR VELOCITY:
  u* = √(τw/ρ) = V√(f/8)

FRICTION REYNOLDS NUMBER (characterises near-wall turbulence):
  Re_τ = u*·(D/2)/ν

  Re_τ < 5     → viscous sublayer
  5 < Re_τ < 30 → buffer layer
  Re_τ > 30    → log-law region

────────────────────────────────────────────────────────────────────────────────
9.  MINOR LOSSES — K-FACTOR METHOD
────────────────────────────────────────────────────────────────────────────────

For fittings, valves, bends, and other local obstructions:
  hL_minor = K · V²/(2g)
  ΔP_minor = K · ρV²/2

  Total head loss per pipe:
    hL_total = (f·L/D + ΣK) · V²/(2g)

  K-FACTOR TABLE (REPRESENTATIVE VALUES):

────────────────────────────────────────────────────────────────────────────────
10.  NETWORK HYDRAULICS — KIRCHHOFF'S LAWS
────────────────────────────────────────────────────────────────────────────────

GRAPH REPRESENTATION:
  A pipe network is a directed graph G = (V, E) where:
    |V| = N nodes (junctions, reservoirs, tanks, demand nodes)
    |E| = P pipes (each carrying flow Qₖ, head loss hLₖ)

  Sign convention: Qₖ > 0 if flow is in the reference direction of pipe k.

KIRCHHOFF'S FIRST LAW (Node Continuity):
  For every node i:
    Σ_{k∈pipes_in(i)} Qₖ − Σ_{k∈pipes_out(i)} Qₖ = dᵢ

  dᵢ = demand (positive = withdrawal, negative = supply).
  For reservoirs: Hᵢ is known (boundary condition), dᵢ is free.
  For junctions: dᵢ = 0 (no net accumulation).

KIRCHHOFF'S SECOND LAW (Energy/Loop Closure):
  For every independent loop ℓ:
    Σ_{k∈loop_ℓ} hLₖ = 0

  hLₖ is positive when flow is in the loop's positive traversal direction.

INDEPENDENT LOOPS:
  Using the co-tree decomposition of a spanning tree T:
    L = P − N + C   (number of independent loops)
  where C = number of connected components (normally C = 1).

  Each co-tree edge (chord) defines one fundamental cycle/loop.

INCIDENCE MATRIX A (N × P):
  Aᵢₖ = +1 if pipe k leaves node i
  Aᵢₖ = −1 if pipe k enters node i
  Aᵢₖ =  0 otherwise

  KCL in matrix form: A · Q = d

LOOP MATRIX B (L × P):
  Bℓₖ = +1 if pipe k is traversed in positive direction in loop ℓ
  Bℓₖ = −1 if pipe k is traversed in negative direction in loop ℓ
  Bℓₖ =  0 if pipe k is not in loop ℓ

  KVL in matrix form: B · hL = 0   where hLₖ = rₖ · Qₖ|Qₖ|

────────────────────────────────────────────────────────────────────────────────
11.  HARDY-CROSS LOOP-CORRECTION METHOD
────────────────────────────────────────────────────────────────────────────────

HISTORY: Hardy Cross (1936) "Analysis of Flow in Networks of Conduits or
Conductors", University of Illinois Bulletin.

ALGORITHM:
  STEP 1: Initialise flows Q⁰ satisfying KCL at all nodes.
           (Set chord flows to 0, solve tree by back-substitution.)

  STEP 2: For each loop ℓ compute the head-loss residual:
            Eℓ = Σₖ∈ℓ rₖ·Qₖ|Qₖ|    (should equal 0 at convergence)

  STEP 3: Compute correction:
            ΔQℓ = −Eℓ / (Σₖ∈ℓ 2rₖ|Qₖ|)

  STEP 4: Apply correction to all pipes in loop ℓ:
            Qₖ += Bℓₖ · ΔQℓ

  STEP 5: Update friction factors (fₖ → Reₖ → Colebrook-White).

  STEP 6: Repeat from STEP 2 until max|ΔQℓ| < tolerance.

RESISTANCE COEFFICIENT:
  rₖ = fₖ · Lₖ / (2g · Aₖ² · Dₖ)
  So that hLₖ = rₖ · Qₖ|Qₖ|    (nonlinear Darcy-Weisbach)

CONVERGENCE: Linear (O(1) per iteration). Typically 20–100 iterations for
small-to-medium networks. May require good initial guess for large networks.

IMPLEMENTATION NOTE:
  Update f at every iteration using current Q to keep the method consistent.
  Loops are processed sequentially (Gauss-Seidel style) rather than in parallel
  to improve convergence rate.

WHEN TO USE: Small networks (< 100 pipes), educational purposes, debugging.
             Prefer Newton-Raphson for large networks in production.

────────────────────────────────────────────────────────────────────────────────
12.  NEWTON-RAPHSON / TODINI-PILATI GRADIENT METHOD
────────────────────────────────────────────────────────────────────────────────

HISTORY: Todini & Pilati (1988) "A gradient algorithm for the analysis of
pipe networks", Computer Applications in Water Supply, Vol. 1.

FORMULATION (head-form, N unknowns):
  State vector: x = H = [H₁, …, HN]ᵀ   (node heads)

  For each pipe k connecting nodes i and j:
    Qₖ(H) = sgn(Hᵢ−Hⱼ) · |Hᵢ−Hⱼ|^(1/2) / rₖ^(1/2)

  Residual equations (N equations):
    Fᵢ(H) = Σₖ Aᵢₖ · Qₖ(H) − dᵢ = 0

  Newton update:
    J · ΔH = −F(H)
    H^(k+1) = H^k + ΔH

JACOBIAN (N×N, sparse, symmetric):
  Jᵢᵢ = Σₖ∈incident(i) |∂Qₖ/∂Hᵢ|
  Jᵢⱼ = −|∂Qₖ/∂Hⱼ|   (for pipe k connecting i and j, i≠j)

  Where: ∂Qₖ/∂H = 1/(2·rₖ^(1/2) · |Hᵢ−Hⱼ|^(1/2))

CONVERGENCE: Quadratic. Typically 5–15 iterations from a reasonable initial guess.

INITIAL GUESS STRATEGY:
  1. Set all node heads = 0.
  2. Set reservoir nodes to their known head values.
  3. Use a spanning-tree BFS to propagate initial heads from reservoirs.

RELAXATION:
  H^(k+1) = H^k + ω·ΔH    (ω = 0.5–1.0; ω=1 is pure Newton)
  Relaxation improves robustness when starting far from solution.

IMPLEMENTATION IN solver.py:
  class NewtonRaphsonSolver:
    def solve(self, nodes, pipes, fluid):
        H = self._initial_heads(nodes, pipes)
        for iteration in range(max_iter):
            Q = self._compute_flows(H, pipes, fluid)
            F = self._residuals(H, Q, nodes, pipes)
            J = self._jacobian(H, pipes, fluid)
            dH = np.linalg.solve(J, -F)
            H += relaxation * dH
            residual = np.max(np.abs(F))
            if residual < tolerance:
                return H, Q, iteration+1, residual
        return H, Q, max_iter, residual

────────────────────────────────────────────────────────────────────────────────
13.  TURBULENCE MODELLING — STANDARD k-ε
────────────────────────────────────────────────────────────────────────────────

THE RANS APPROACH:
  Decompose velocity: u = Ū + u'   (mean + fluctuation)
  Averaging the NS equations introduces the Reynolds stress tensor:
    τᵢⱼ_R = −ρ <u'ᵢu'ⱼ>

  The Boussinesq hypothesis approximates it as:
    τᵢⱼ_R = μt (∂Uᵢ/∂xⱼ + ∂Uⱼ/∂xᵢ) − (2/3)ρkδᵢⱼ

TRANSPORT EQUATIONS (Launder & Spalding 1974):

  Turbulence kinetic energy k [m²/s²]:
    ρ(∂k/∂t + U·∇k) = ∇·[(μ + μt/σk)∇k] + Gk − ρε

  Turbulent dissipation rate ε [m²/s³]:
    ρ(∂ε/∂t + U·∇ε) = ∇·[(μ + μt/σε)∇ε] + C₁ε(ε/k)Gk − C₂ε ρε²/k

  Turbulent viscosity:
    μt = ρ Cμ k²/ε

  STANDARD CONSTANTS:
    Cμ = 0.09,  C₁ε = 1.44,  C₂ε = 1.92,  σk = 1.0,  σε = 1.30

WALL FUNCTIONS (y⁺ > 30):
  u⁺ = (1/κ) ln(y⁺) + B    κ = 0.41, B ≈ 5.5 (smooth walls)
  y⁺ = y·u*/ν              (dimensionless wall distance)
  u⁺ = u/u*                 (dimensionless velocity)

PIPE-FLOW k-ε ESTIMATES (for our 1D model):
  u* = V√(f/8)                       (shear velocity from DW friction)
  k  = u*² / √Cμ ≈ 3.33 u*²         (fully-developed approximation)
  ε  = Cμ^(3/4) k^(3/2) / (κ δ)     (δ = D/4, pipe half-radius)
  μt = ρ Cμ k²/ε

  Turbulence intensity:
    I = u'/U ≈ 0.16 Re^(−1/8)        (empirical, smooth pipe, turbulent)

────────────────────────────────────────────────────────────────────────────────
14.  HEAT TRANSFER IN PIPE FLOW
────────────────────────────────────────────────────────────────────────────────

FORCED CONVECTION — NUSSELT NUMBER CORRELATIONS:

  GNIELINSKI (1975) — Best for 3000 < Re < 5×10⁶:
    Nu = (f/8)(Re−1000)Pr / [1 + 12.7√(f/8)(Pr^(2/3)−1)]

    Valid: 0.5 < Pr < 2000, L/D > 10
    Uncertainty: ±10%

  DITTUS-BOELTER (1930) — Turbulent only, Re > 10 000:
    Nu = 0.023 Re⁰·⁸ Prⁿ
    n = 0.4 (fluid being heated), n = 0.3 (fluid being cooled)
    Valid: 0.6 < Pr < 160

  SIEDER-TATE (1936) — Accounts for viscosity variation:
    Nu = 0.027 Re⁰·⁸ Pr^(1/3) (μ/μw)^0.14
    (μw = viscosity at wall temperature)

  LAMINAR — GRAETZ PROBLEM (constant heat flux, Re < 2300):
    Nu = 3.66 + 0.0668·Gz / (1 + 0.04·Gz^(2/3))
    Gz = Re·Pr·D/L   (Graetz number — thermal entry length parameter)

    Thermally fully-developed limit: Nu → 3.657 (constant T_wall) or 4.364 (const flux)

CONVECTION COEFFICIENT:
  h = Nu · k_fluid / D   [W/(m²·K)]

HEAT TRANSFER RATE:
  Q̇ = h · (πDL) · ΔT_lm   [W]
  ΔT_lm = (ΔT₁ − ΔT₂) / ln(ΔT₁/ΔT₂)   (log-mean temperature difference)

OUTLET TEMPERATURE (constant wall temperature Tw):
  Tout = Tw − (Tw − Tin)·exp(−h·πDL / (ṁcₚ))

NTU METHOD:
  NTU = h·A / (ṁcₚ)    (number of transfer units)
  ε   = 1 − exp(−NTU)  (heat exchanger effectiveness for const Tw)
  Q̇   = ε · ṁcₚ · (Tw − Tin)

THERMAL ENTRY LENGTH:
  Laminar:   Le_thermal ≈ 0.05 Re·Pr·D
  Turbulent: Le_thermal ≈ 10 D (develops quickly)

────────────────────────────────────────────────────────────────────────────────
15.  WATER HAMMER — METHOD OF CHARACTERISTICS
────────────────────────────────────────────────────────────────────────────────

WAVE SPEED:
  a = √(K/ρ) / √(1 + (K/E)·(D/t))   [m/s]
  
  Typical values:
    Steel pipe, water: a ≈ 1200–1400 m/s
    PVC pipe, water:   a ≈  300–600  m/s
    Copper pipe:       a ≈  900–1100 m/s

JOUKOWSKY PRESSURE RISE (instantaneous closure):
  ΔP = ρ · a · ΔV
  
  EXAMPLE: Water, a=1200 m/s, ρ=998 kg/m³, ΔV=2 m/s (valve slams shut):
    ΔP = 998 × 1200 × 2 = 2 395 200 Pa ≈ 23.5 atm!

VALVE CLOSURE CRITERION:
  Critical closure time: tc = 2L/a
  - If tc_valve ≤ tc: "sudden" closure → full Joukowsky pressure rise
  - If tc_valve > tc: "slow" closure → reduced ΔP ≈ ΔP_J · (tc/tc_valve)

METHOD OF CHARACTERISTICS (MOC) DISCRETISATION:
  Grid: Δx = a·Δt (Courant number Cr = 1 exactly)
  
  Interior points:
    HP = (HA + HB)/2 + (a/2gA)(QA − QB) − (R·Δt/2)(QA|QA| + QB|QB|)
    QP = (QA + QB)/2 + (gA/2a)(HA − HB) − ...
    
    where R = f/(2gDA²) is the resistance term.

  BOUNDARY CONDITIONS:
    Reservoir: HP = Hreservoir (constant head), QP solved from C⁺ or C⁻ alone.
    Dead end:  QP = 0, HP solved from the approaching characteristic.
    Pump:      HP − HB = Cpump(QP) (pump head-flow curve, solved simultaneously).
    Valve:     QP = Cd·Av(t)·√(2g·HP), Av decreasing linearly or as a ramp.

CODE REFERENCE:
  class WaterHammerSolver in solver.py, method solve_transient().
  Returns: list of time steps, each with arrays of H and Q for all nodes/pipes.

────────────────────────────────────────────────────────────────────────────────
16.  TWO-PHASE FLOW — LOCKHART-MARTINELLI
────────────────────────────────────────────────────────────────────────────────

MODEL ASSUMPTIONS:
  • Separated flow: liquid and gas flow in parallel streams.
  • Each phase has its own pressure gradient based on single-phase DW.
  • The two-phase multiplier Φ² accounts for interaction.

INDIVIDUAL PHASE PRESSURE GRADIENTS:
  (dP/dz)_L = f_L · ρ_L · v_L² / (2D)    (liquid flowing alone in pipe)
  (dP/dz)_G = f_G · ρ_G · v_G² / (2D)    (gas flowing alone in pipe)

LOCKHART-MARTINELLI PARAMETER:
  X² = (dP/dz)_L / (dP/dz)_G

TWO-PHASE MULTIPLIER (Chisholm 1967):
  Φ²_L = 1 + C/X + 1/X²
  
  CONSTANT C:
  ┌──────────────────────────────┬───┐
  │ Liquid-turbulent / Gas-turb  │ 21│
  │ Liquid-laminar  / Gas-turb   │ 12│
  │ Liquid-turbulent / Gas-lam   │ 10│
  │ Liquid-laminar  / Gas-lam    │  5│
  └──────────────────────────────┴───┘

TWO-PHASE PRESSURE GRADIENT:
  (dP/dz)_TP = Φ²_L · (dP/dz)_L

VOID FRACTION:
  Homogeneous: α_h = Q_G / (Q_L + Q_G)    (volume-based)
  Martinelli:  α_M = 1 / (1 + 0.28 X^0.71)
  
  Slip ratio (liquid velocity / gas velocity): S = v_G/v_L varies with flow pattern.

────────────────────────────────────────────────────────────────────────────────
17.  COMPRESSIBLE GAS FLOW IN PIPES
────────────────────────────────────────────────────────────────────────────────

SPEED OF SOUND:
  a = √(γRT)    [m/s]    for ideal gas
  
  Air at 20°C: a = √(1.4 × 287 × 293.15) = 343 m/s

MACH NUMBER:
  M = V/a

ISENTROPIC FLOW RELATIONS (no friction, perfect nozzle):
  p/p₀ = (1 + (γ−1)/2 · M²)^(−γ/(γ−1))
  T/T₀ = (1 + (γ−1)/2 · M²)^(−1)
  ρ/ρ₀ = (1 + (γ−1)/2 · M²)^(−1/(γ−1))

CRITICAL (CHOKED) CONDITIONS:
  At M = 1 (throat of nozzle or end of Fanno duct):
    p*/p₀ = [2/(γ+1)]^(γ/(γ−1)) = 0.5283 for air
    T*/T₀ = 2/(γ+1)               = 0.8333 for air
    ρ*/ρ₀ = [2/(γ+1)]^(1/(γ−1))  = 0.6339 for air

FANNO LINE (adiabatic pipe flow with friction, variable M along length):
  Maximum dimensionless duct length:
    4f·L*_max/D = (1−M²)/(γM²) + (γ+1)/(2γ) ln[(γ+1)M²/(2+(γ−1)M²)]
  
  For M<1: flow accelerates toward choke; adding pipe length reduces max Q.
  For M>1: flow decelerates toward choke; adding pipe length causes oblique shock.

WHEN COMPRESSIBLE EFFECTS MATTER:
  M < 0.3: incompressible assumption error < 5% (safe to use DW)
  M > 0.3: compressible corrections needed
  M = 1.0: choked — cannot increase flow by reducing downstream pressure

────────────────────────────────────────────────────────────────────────────────
18.  CAVITATION AND NPSH
────────────────────────────────────────────────────────────────────────────────

CAVITATION occurs when local static pressure drops below the vapour pressure
of the liquid, causing vapour bubbles to form and implode.

CAVITATION NUMBER (σ):
  σ = (p − pv) / (½ρV²)

  σ < 0: cavitation certain
  σ ≈ 0: incipient cavitation
  σ >> 1: no cavitation

VAPOUR PRESSURE (water):
  T=20°C: pv = 2 337 Pa
  T=60°C: pv = 19 940 Pa
  T=100°C: pv = 101 325 Pa (boils at atmospheric)

NET POSITIVE SUCTION HEAD (NPSH):
  NPSH_available = (p_atm − pv)/(ρg) + z_suction   [m]
  
  Design requirement: NPSH_available > NPSH_required (from pump curve) + safety margin.
  
  Margin: NPSH_a must exceed NPSH_r by at least 0.5–1.0 m in practice.

26.  IMPLEMENTING THE COLEBROOK-WHITE FRICTION FACTOR
────────────────────────────────────────────────────────────────────────────────

FULL PYTHON IMPLEMENTATION:

  def friction_factor_colebrook_white(
      re: float, eps_d: float, max_iter: int = 50
  ) -> float:
      """
      Colebrook-White friction factor for turbulent pipe flow.
      
      Args:
          re:       Reynolds number (dimensionless)
          eps_d:    Relative roughness ε/D (dimensionless, ≥ 0)
          max_iter: Maximum Picard iterations
          
      Returns:
          Darcy friction factor f (dimensionless)
          
      References:
          Colebrook, C.F. & White, C.M. (1937). Experiments with fluid
          friction in roughened pipes. Proc. Roy. Soc. A, 161, 367–381.
      """
      if re <= 0:
          return float("nan")
      if re < 2300.0:
          return 64.0 / re       # Exact Hagen-Poiseuille
      
      # Swamee-Jain as initial guess (avoids sqrt(f) instability near 0)
      if eps_d > 0.0:
          f = 0.25 / (math.log10(eps_d / 3.7 + 5.74 / re ** 0.9)) ** 2
      else:
          f = 0.316 / re ** 0.25  # Blasius (smooth, Re<1e5) as fallback
      
      # Picard iteration on 1/√f form
      for _ in range(max_iter):
          inner = eps_d / 3.7 + 2.51 / (re * math.sqrt(f))
          if inner <= 0.0:
              break
          rhs = -2.0 * math.log10(inner)
          f_new = 1.0 / (rhs * rhs)
          if abs(f_new - f) < 1.0e-12:
              f = f_new
              break
          f = f_new
      
      return f

VALIDATION (compare to tabulated Moody chart values):
  Test case 1: Re=10000,  ε/D=0.001  → f ≈ 0.03160 ± 0.0005

27.  HARDY-CROSS SOLVER — STEP-BY-STEP
────────────────────────────────────────────────────────────────────────────────

COMPLETE ALGORITHM WALKTHROUGH with a 3-loop example network:

  Network: 6 nodes (N1–N6), 7 pipes (P1–P7), 2 loops
    N1 (reservoir, H=50m) → P1 → N2 → P3 → N4 (demand 10 L/s)
    N2 → P2 → N3 → P4 → N5 → P5 → N4
    N3 → P6 → N6 → P7 → N5

  INITIALISATION:
    Spanning tree: N1–N2–N3–N4–N5
    Tree pipes: P1 (Q=0.010), P2 (Q=0.006), P3 (Q=0.004), P5 (Q=0.004)
    Chord (co-tree): P6 (Q=0), P7 (Q=0)

  ITERATION 1:
    Loop 1 contains pipes: P2, P4, P3 (in positive direction)
      r2 = f2·L2/(2gA2²D2)
      E1 = r2·Q2|Q2| − r3·Q3|Q3| + r4·Q4|Q4|
      ΔQ1 = −E1 / (2(r2|Q2| + r3|Q3| + r4|Q4|))
      Update: Q2 += ΔQ1, Q3 += ΔQ1, Q4 += ΔQ1
    
    Loop 2 contains pipes: P4, P6, P7, P5 (traversal direction)
      E2 = r4·Q4|Q4| + r6·Q6|Q6| − r7·Q7|Q7| − r5·Q5|Q5|
      ΔQ2 = −E2 / (2(r4|Q4| + r6|Q6| + r7|Q7| + r5|Q5|))
      Update all pipes in loop 2.

  Repeat until max|ΔQ| < 10⁻⁶.

COMMON ISSUES AND FIXES:
  Problem: Divergence / oscillation
  Fix:     Check that all loops have at least one non-zero initial flow.
           Ensure head boundary conditions are set on at least one node.

  Problem: Very slow convergence (>200 iterations)
  Fix:     The initial flow guess is far from solution.
           Use NetworkTopology.bfs_flow_init() which propagates flows from
           the reservoir along the spanning tree.

  Problem: NaN friction factor
  Fix:     Q=0 gives Re=0; protect with: if Q == 0: hL = 0; continue

28.  NEWTON-RAPHSON SOLVER — STEP-BY-STEP
────────────────────────────────────────────────────────────────────────────────

JACOBIAN CONSTRUCTION:

  For a 4-node network (N1=reservoir at H=50m, N2, N3, N4=demand 0.01 m³/s)
  with pipes P12, P23, P24, P34 (all connecting adjacent nodes):

  Pipe flows as function of heads:
    Q_12 = sgn(H1−H2) · |H1−H2|^0.5 / r_12^0.5
    (similarly for all pipes)

  Residuals (3 equations for 3 unknown heads H2, H3, H4):
    F2 = Q_12 − Q_23 − Q_24 − d2 = 0
    F3 = Q_23 − Q_34 − d3 = 0
    F4 = Q_24 + Q_34 − d4 = 0

  Jacobian (3×3):
    J[2,2] = ∂F2/∂H2 = −∂Q12/∂H2 − ∂Q23/∂H2 − ∂Q24/∂H2
    J[2,3] = ∂F2/∂H3 = +∂Q23/∂H3
    J[2,4] = ∂F2/∂H4 = +∂Q24/∂H4
    ... (symmetric)

  Where ∂Q_ij/∂Hi = |Hi−Hj|^(−1/2) / (2 r_ij^(1/2))  (always positive)

  Newton step: [H2,H3,H4]^(k+1) = [H2,H3,H4]^k − J⁻¹ · F

PYTHON PATTERN:
  J = np.zeros((n_free, n_free))
  F = np.zeros(n_free)
  
  for pipe in pipes:
      i = node_index[pipe.from_node]
      j = node_index[pipe.to_node]
      dH = H[i] - H[j]
      if abs(dH) < 1e-15:
          dQ_dH = 1e6   # regularisation
      else:
          dQ_dH = 1.0 / (2.0 * r[pipe.id]**0.5 * abs(dH)**0.5)
      
      Q = np.sign(dH) * abs(dH)**0.5 / r[pipe.id]**0.5
      
      if i not in fixed and j not in fixed:
          J[i,i] += dQ_dH;  J[j,j] += dQ_dH
          J[i,j] -= dQ_dH;  J[j,i] -= dQ_dH
      
      F[i] -= Q;  F[j] += Q
  
  dH = np.linalg.solve(J[free][:,free], -F[free])
  H[free] += relaxation * dH

29.  WATER-HAMMER MOC SOLVER
────────────────────────────────────────────────────────────────────────────────

FILE LOCATION: class WaterHammerSolver in solver.py (lines ~2051–2200)

GRID SETUP:
  For a single pipe of length L:
    Choose N_reaches (number of segments)
    Δx = L / N_reaches
    Δt = Δx / a  (satisfies Courant condition exactly)
    N_steps = int(t_total / Δt) + 1

  Storage arrays:
    H[N_reaches+1] — head at each section boundary
    Q[N_reaches+1] — flow at each section boundary

INTERIOR POINT UPDATE (forward time step):
  For j = 1 to N_reaches - 1:
    # C+ characteristic from j-1
    CP = H[j-1] + (a/(g*A)) * Q[j-1] - R*Δt * Q[j-1]*|Q[j-1]|
    # C- characteristic from j+1
    CM = H[j+1] - (a/(g*A)) * Q[j+1] + R*Δt * Q[j+1]*|Q[j+1]|
    
    H_new[j] = (CP + CM) / 2
    Q_new[j] = (g*A/a) * (CP - CM) / 2

  where R = f/(2*g*D*A²) is the friction resistance coefficient.

UPSTREAM BOUNDARY (reservoir):
  H_new[0] = H_reservoir   (constant head)
  # Use C- characteristic from j=1 to find Q_new[0]:
  CM = H[1] - (a/(g*A))*Q[1] + R*Δt*Q[1]*|Q[1]|
  Q_new[0] = (g*A/a) * (H_reservoir - CM)

DOWNSTREAM BOUNDARY (valve closure):
  Valve closure function: τ(t) = (1 - t/t_close)² for linear closure
  Q_new[N] = Q0 * τ(t_current)   (or 0 for instant closure)
  # Use C+ from j=N-1:
  CP = H[N-1] + (a/(g*A))*Q[N-1] - R*Δt*Q[N-1]*|Q[N-1]|
  H_new[N] = CP - (a/(g*A))*Q_new[N]

30.  NETWORK TOPOLOGY ANALYSIS
────────────────────────────────────────────────────────────────────────────────

FILE: class NetworkTopology in solver.py

KEY METHODS:

  bfs(start_node, adjacency) → list[str]
    Breadth-first search from start_node. Returns nodes in BFS order.
    Used to: detect connected components, find path from reservoir to any node.

  spanning_tree(nodes, pipes) → (tree_pipes, chord_pipes)
    Builds a minimum spanning tree using BFS.
    tree_pipes:  pipes forming the tree (N-1 pipes for N nodes)
    chord_pipes: remaining pipes (co-tree), one per independent loop

  fundamental_loops(tree_pipes, chord_pipes, nodes) → list[list[(pipe_id, sign)]]
    For each chord pipe, traces the unique path in the spanning tree between
    its two endpoints, forming one fundamental loop.
    Returns: list of loops, each a list of (pipe_id, +1 or -1) tuples.

  incidence_matrix(nodes, pipes) → np.ndarray
    Returns the N × P incidence matrix A.
    Used by Newton-Raphson for Jacobian structure.

  connected_components(nodes, pipes) → list[list[str]]
    Returns groups of mutually reachable nodes.
    A valid network must have exactly one connected component.

VALIDATION CHECKS performed before solving:
  ✓ Graph is connected (single component)
  ✓ At least one fixed-head node (reservoir) exists
  ✓ All pipe endpoints are valid node IDs
  ✓ No duplicate pipe IDs or node IDs
  ✓ All pipe lengths > 0, diameters > 0
  ✓ Global demand balance: |ΣQ_supply − ΣQ_demand| < tolerance

35.  DEBUGGING TIPS FOR THE SOLVER
────────────────────────────────────────────────────────────────────────────────

SYMPTOM: Solver does not converge (max iterations reached)
CHECKS:
  1. Is there at least one fixed-head node? (reservoir / tank)
  2. Is the network fully connected? (no isolated sub-graphs)
  3. Does total demand equal total supply (mass balance)?
  4. Are there any pipes with zero length or diameter?
  5. Try reducing relaxation factor (0.5 instead of 1.0).
  6. Try Hardy-Cross first to verify topology is solvable, then switch to NR.

SYMPTOM: NaN values in results
CHECKS:
  1. Q=0 in a pipe → Re=0 → Colebrook returns 64/0 for transitional check.
     Guard: if abs(Q) < 1e-15: hL = 0; continue
  2. Negative head difference → sqrt(negative) in Newton pipe-flow formula.
     Guard: if abs(dH) < 1e-15: dQ = 0.0

SYMPTOM: Oscillating convergence (alternating positive/negative ΔQ)
FIX: Reduce relaxation to ω = 0.3–0.5. This is common in networks with
     highly unequal pipe diameters (stiff systems).

SYMPTOM: Very high velocities (>10 m/s) causing cavitation warnings
CHECK: Pipe diameters may be too small. Use the pipe-sizing calculator
       to find a suitable diameter for the target flow rate.

SYMPTOM: Pressure results look wrong (all positive, or all zero)
CHECK: Verify that reservoir nodes have pressure_known=True and a sensible
       pressure_value (e.g., 200000 Pa for a 20 m head).

  • Provides add/update/delete/get methods for nodes and pipes.

  • Fires change events so the canvas and UI stay in sync.
  • Serialises/deserialises from API response format.

UNDO/REDO STACK:
  Uses a command pattern. Each mutating operation pushes a deep clone of the
  current state onto _history. Undo pops from _history and pushes current
  state onto _future. Redo pops from _future.

  Maximum stack depth: 50 states.

AUTO-PIPE-LENGTH:
  When a pipe is added in the canvas, length is auto-calculated from the
  Euclidean distance between nodes (assuming 1 canvas unit = 1 metre):
    length = √((x₂−x₁)² + (y₂−y₁)²) * scale_factor

SOLVER SETTINGS:
  NetworkManager.getSolverSettings() returns:
    { type, maxIterations, tolerance, relaxation, fluid, temperature }

CORE PATTERN:
  async function _request(method, path, body = null) {
      const opts = {
          method,
          headers: { "Content-Type": "application/json" }
      };
      if (body) opts.body = JSON.stringify(body);
      const resp = await fetch(`${API_BASE}${path}`, opts);
      if (!resp.ok) {
          const err = await resp.json().catch(() => ({}));
          throw new Error(err.detail ?? `HTTP ${resp.status}`);
      }
      return resp.json();
  }

49.  CONVERGENCE PLOT
────────────────────────────────────────────────────────────────────────────────

Rendered by ConvergencePlot.draw() in solver.js onto a 300×120 px canvas.

  X-axis: Iteration number
  Y-axis: log₁₀(residual)   [flow balance error, m³/s]
  
  A dashed red line marks the minimum residual reached.
  A well-converged Newton-Raphson solve shows a steep S-curve:
    • Slow initial descent (far from solution)

50.  HYDRAULIC GRADE LINE (HGL) OVERLAY
────────────────────────────────────────────────────────────────────────────────

Module: HydraulicGradientLine in solver.js.

  HGL = elevation + pressure head = z + p/(ρg)   [m above datum]

The overlay draws a line segment for each pipe from the HGL at the start node
to the HGL at the end node, overlaid on the canvas in a contrasting colour.

The slope of the HGL over each pipe:
  S = (HGL_in − HGL_out) / L = hL / L   [m/m]

  For a well-designed system: S < 0.01 (< 1% gradient)
  For pumping systems: the HGL rises at pump locations.

61.  MATHEMATICAL APPENDIX
────────────────────────────────────────────────────────────────────────────────

A.1  BUCKINGHAM PI THEOREM APPLIED TO PIPE FLOW

  Variables: Δp, ρ, V, D, μ, L, ε   (7 variables, 3 base dimensions: M, L, T)
  Number of Π groups: 7 − 3 = 4

  Π₁ = Δp/(ρV²)         → Euler number Eu
  Π₂ = ρVD/μ            → Reynolds number Re
  Π₃ = L/D              → Aspect ratio (slenderness)
  Π₄ = ε/D              → Relative roughness

  Functional relationship:
    Eu = f(Re, L/D, ε/D)
    Δp = ρV² · f(Re, ε/D) · L/D   → gives Darcy-Weisbach!

A.2  INCIDENCE MATRIX RELATIONS

  A · Q = d    (KCL at all nodes)
  Aᵀ · H = hL  (head-loss = head difference per pipe)

  Combined: A · R⁻¹ · Aᵀ · H = d
    where R = diag(rₖ) is the resistance matrix (linearised)
    This is the N×N symmetric positive definite system solved by NR.

A.3  ENERGY EQUATION IN PIPE NETWORKS

  Total energy (Bernoulli + losses):
    H_in = H_out + hL − hP
    where hP = pump head added, hL = sum of friction + minor losses

  Hydraulic Grade Line:
    HGL = H − V²/(2g)   (removes velocity head)

  Energy Grade Line:
    EGL = H = HGL + V²/(2g)   (total head)

A.4  WAVE PROPAGATION VELOCITY DERIVATION

  From elastic wave theory in a fluid-filled tube:
    Equation of motion: ρ ∂V/∂t + ∂p/∂x = 0
    Continuity:         ∂p/∂t + K ∂V/∂x = −K·α·(D/Et)·∂p/∂t

  Combining: ∂²p/∂t² = a² ∂²p/∂x²    (wave equation)
  where: a = √(K/ρ) · 1/√(1 + KD/(Et))

A.5  GNIELINSKI CORRELATION DERIVATION

  Based on the modified Prandtl analogy (Petukhov 1970):
    Nu = (f/8)·Re·Pr / [1 + 12.7·√(f/8)·(Pr^(2/3)−1)]

  Modified by Gnielinski (1975) by replacing Re with (Re−1000):
    Nu = (f/8)·(Re−1000)·Pr / [1 + 12.7·√(f/8)·(Pr^(2/3)−1)]

  Improvement: better accuracy for 3000 < Re < 10000 (entry region).

62.  SOLVER VALIDATION TEST CASES
────────────────────────────────────────────────────────────────────────────────

TEST CASE 1 — Laminar flow in series pipe:
  Pipe: L=10m, D=0.01m, water 20°C, Q=1.0e-5 m³/s
  Re = Q/(πD²/4) / ν = 1.273e-3 / 1.004e-6 = 1268 → laminar
  f = 64/1268 = 0.05047
  hL = 0.05047 × (10/0.01) × (1.273e-3 / (2×9.806)) = 0.0416 m
  Expected Δp = ρg·hL = 998 × 9.806 × 0.0416 = 407 Pa

  COMPUTED: hL=0.04162 m, Δp=407.5 Pa  ✓

TEST CASE 2 — Turbulent flow in rough pipe:
  Pipe: L=100m, D=0.1m, ε=0.000046m, water 20°C, Q=0.02 m³/s
  V = 0.02/(π×0.1²/4) = 2.546 m/s
  Re = 2.546 × 0.1 / 1.004e-6 = 253,586 → turbulent
  ε/D = 0.000046/0.1 = 0.00046
  f_CW = 0.01914 (Colebrook-White)
  hL = 0.01914 × (100/0.1) × 2.546²/(2×9.806) = 6.32 m

  COMPUTED: hL=6.319 m  ✓

TEST CASE 3 — Hardy-Cross 3-loop network (textbook: Streeter & Wylie):
  8 nodes, 11 pipes.
  After convergence, verify:
    Sum of flows at every junction ≈ 0 (< 1e-8 m³/s)
    Sum of head losses around every loop ≈ 0 (< 1e-6 m)

TEST CASE 4 — Water hammer (instantaneous valve closure):
  L=1000m, D=0.3m, t=10mm, E_steel=200GPa, ρ=998, V₀=2.0 m/s
  a = √(2.15e9/998) / √(1 + 2.15e9×0.3/(200e9×0.01))
    = 1468 / √(1 + 0.3225) = 1468/1.151 = 1275 m/s
  ΔP = 998 × 1275 × 2.0 = 2,547,900 Pa ≈ 25.2 bar

  COMPUTED: a=1273 m/s, ΔP=2544 kPa  ✓
