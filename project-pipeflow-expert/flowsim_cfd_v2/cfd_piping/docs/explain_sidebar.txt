================================================================================
 CODE EXPLANATION — Sidebar.tsx
 FlowSim CFD Navigation Sidebar Component
================================================================================

This file creates the LEFT SIDEBAR of the FlowSim CFD web application.
It contains the logo, navigation links, and a footer status bar.

================================================================================
 SECTION 1 — IMPORTS
================================================================================

CODE:
  import { NavLink } from 'react-router-dom'

EXPLANATION:
  Imports NavLink from the React Router library.
  NavLink is a special version of a clickable link (<a> tag) that knows
  whether the current page URL matches the link's destination.
  It automatically adds an "active" state when you are on that page.
  This is how the sidebar knows to highlight the current page in blue.

----

CODE:
  import {
    LayoutDashboard, FolderOpen, Network, Play,
    BarChart3, Waves, FlaskConical, Wrench, Droplets,
    ChevronRight,
  } from 'lucide-react'

EXPLANATION:
  Imports icon components from the Lucide React icon library.
  Lucide is a library of clean, consistent SVG icons.
  Each name (LayoutDashboard, FolderOpen, etc.) is one icon.
  They are used as visual symbols next to each navigation label.

  Icon          Used for
  ------------- -----------------------
  LayoutDashboard  Dashboard page
  FolderOpen       Projects page
  Play             Simulations page
  BarChart3        Pipe Analysis page
  Waves            Moody Chart page + Logo
  Droplets         Fluid Library page
  Wrench           Diagnostics page
  ChevronRight     Arrow shown on active item (>)

  Note: Network and FlaskConical are imported but not used in this file.
  They were probably planned for future navigation items.

----

CODE:
  import { clsx } from 'clsx'

EXPLANATION:
  Imports the clsx utility function.
  clsx builds a CSS class string from multiple values conditionally.
  Example:
    clsx('base-class', isActive ? 'active-class' : 'inactive-class')
    When isActive=true  → returns 'base-class active-class'
    When isActive=false → returns 'base-class inactive-class'
  This is used to change the link colors based on whether the page
  is currently active or not.


================================================================================
 SECTION 2 — NAV_ITEMS ARRAY (the navigation menu data)
================================================================================

CODE:
  const NAV_ITEMS = [
    { to: '/dashboard',    icon: LayoutDashboard,	label: 'Dashboard' },
    { to: '/projects',     icon: FolderOpen,       label: 'Projects' },
    { to: '/simulations',  icon: Play,             label: 'Simulations' },
    { to: '/analysis',     icon: BarChart3,        label: 'Pipe Analysis' },
    { to: '/moody-chart',  icon: Waves,            label: 'Moody Chart' },
    { to: '/fluids',       icon: Droplets,         label: 'Fluid Library' },
    { to: '/diagnostics',  icon: Wrench,           label: 'Diagnostics' },
  ]

EXPLANATION:
  This is a JavaScript array of objects. Each object represents one
  navigation item in the sidebar menu.

  Each object has 3 properties:

  PROPERTY  TYPE              MEANING
  --------- ----------------- ------------------------------------------
  to        string            The URL path this link navigates to.
                              Example: '/dashboard' goes to the Dashboard page.
  icon      React component   The Lucide icon to show next to the label.
                              Stored as a reference (not rendered yet).
  label     string            The text displayed next to the icon.
                              Example: 'Pipe Analysis'

  WHY DO IT THIS WAY?
  Instead of writing 7 separate <NavLink> elements by hand (which would
  be repetitive), the data is stored in an array and then .map() is used
  to generate all 7 links automatically. This is the DRY principle:
  Don't Repeat Yourself. If you want to add a new page, just add one
  object to NAV_ITEMS.

================================================================================
 SECTION 5 — NAVIGATION LINKS
================================================================================

CODE:
  <nav className="flex-1 overflow-y-auto py-3 px-2">
    <div className="space-y-0.5">
      {NAV_ITEMS.map(({ to, icon: Icon, label }) => (
        <NavLink
          key={to}
          to={to}
          className={({ isActive }) =>
            clsx(
              'flex items-center gap-3 px-3 py-2 rounded-lg text-sm font-medium transition-all duration-150',
              isActive
                ? 'bg-flow-50 text-flow-700'
                : 'text-slate-600 hover:bg-slate-50 hover:text-slate-900',
            )
          }
        >
          {({ isActive }) => (
            <>
              <Icon size={16} className={isActive ? 'text-flow-600' : 'text-slate-400'} />
              <span className="flex-1">{label}</span>
              {isActive && <ChevronRight size={12} className="text-flow-400" />}
            </>
          )}
        </NavLink>
      ))}
    </div>
  </nav>

EXPLANATION:

  <nav className="flex-1 overflow-y-auto py-3 px-2">
    nav            → HTML5 semantic navigation element.
    flex-1         → Takes all remaining space between logo and footer.
    overflow-y-auto → If nav items overflow vertically, show a scrollbar.
    py-3           → Vertical padding 12px top and bottom.
    px-2           → Horizontal padding 8px left and right.

  <div className="space-y-0.5">
    space-y-0.5    → Adds 2px vertical gap between each nav item.

  NAV_ITEMS.map(({ to, icon: Icon, label }) => (...))
    → Loops through all 7 items in NAV_ITEMS array.
    → For each item, it destructures the 3 properties:
        to    → the URL path
        icon  → renamed to "Icon" with capital I (React requires components
                to start with uppercase)
        label → the text label
    → Renders one <NavLink> for each item.

  key={to}
    → React requires a unique "key" prop for each item in a list.
    → Uses the URL path (like '/dashboard') as the unique key.

  to={to}
    → Tells NavLink which URL to navigate to when clicked.

  className={({ isActive }) => clsx(...)}
    → NavLink passes an object with "isActive" boolean to the className function.
    → isActive is TRUE when the browser URL matches this link's "to" path.
    → clsx combines CSS classes conditionally:

    Always applied:
      flex items-center    → Side-by-side icon and text.
      gap-3                → 12px gap between icon and text.
      px-3 py-2            → Padding: 12px horizontal, 8px vertical.
      rounded-lg           → Rounded corners.
      text-sm font-medium  → 14px medium weight text.
      transition-all duration-150 → Smooth 150ms animation on hover.

    When ACTIVE (current page):
      bg-flow-50           → Very light blue background highlight.
      text-flow-700        → Dark blue text color.

    When NOT active (other pages):
      text-slate-600       → Gray text.
      hover:bg-slate-50    → Light gray background on mouse hover.
      hover:text-slate-900 → Dark text on mouse hover.

  {({ isActive }) => (...)}
    → NavLink also passes isActive to its CHILDREN (the content inside).
    → This is a "render prop" pattern: passing a function as children
      so the children can access the isActive state.

  <>...</>
    → React Fragment. Groups multiple elements without adding a real DOM element.
    → Needed because JSX must return a single root element.

  <Icon size={16} className={isActive ? 'text-flow-600' : 'text-slate-400'} />
    → Renders the icon for this nav item.
    → Icon is the component (e.g., LayoutDashboard, FolderOpen).
    → size={16} = 16x16 pixels.
    → When active: blue icon (text-flow-600 = #0269c8).
    → When inactive: gray icon (text-slate-400).

  <span className="flex-1">{label}</span>
    → Displays the text label (e.g., "Dashboard", "Projects").
    → flex-1 makes this span take all available horizontal space,
      pushing the ChevronRight arrow to the far right.

  {isActive && <ChevronRight size={12} className="text-flow-400" />}
    → Only renders the right-arrow icon (>) when this link IS active.
    → "isActive && ..." is short-circuit evaluation:
        If isActive = false: renders nothing.
        If isActive = true: renders <ChevronRight />.
    → This gives a visual indicator of the currently selected page.

  VISUAL RESULT of one active nav item:
    [icon]  Dashboard              >
    (blue bg, blue text, blue arrow on right)

  VISUAL RESULT of one inactive nav item:
    [icon]  Projects
    (white bg, gray text, no arrow)

================================================================================
 KEY CONCEPTS USED IN THIS FILE
================================================================================

CONCEPT              EXPLANATION
-------------------- ----------------------------------------------------------
NavLink              React Router link with built-in active state detection.
                     Better than <Link> for navigation menus.

isActive             Boolean automatically provided by NavLink.
                     true = you are currently on this page.
                     false = you are on a different page.

Render Props         Passing a function as children to a component so the
                     children can access the component's internal state.
                     Used twice: once for className, once for children of NavLink.

clsx()               Utility for conditional CSS class names.
                     Cleaner than string template literals for multiple conditions.

Array.map()          Transforms the NAV_ITEMS data array into JSX elements.
                     Core React pattern: data → UI.

Tailwind CSS         Utility-first CSS framework. Each class is one CSS property.
                     No separate .css file needed.

Destructuring        { to, icon: Icon, label } extracts values from each
with rename          NAV_ITEMS object. "icon: Icon" renames "icon" to "Icon"
                     (capital I) so React treats it as a component.

Short-circuit (&&)   {isActive && <Component />} renders the component
evaluation           only when isActive is true. Standard React pattern
                     for conditional rendering.

export default       Makes this function available for import in other files.
                     Used in Layout.tsx as: import Sidebar from './Sidebar'
